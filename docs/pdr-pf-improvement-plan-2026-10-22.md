## ② 改善方針

1. **位置と運動状態を同じ生成過程で決める。** 方位・倍率・一時的残差を抽出し、その値から位置を計算する。採用位置から逆算した角度を恒久方位補正へ無条件に書き込まない。
2. **PDRは不確かな入力として使う。** 粒子別drift・stride倍率・離散運動状態を維持し、後の地図整合によって異なる仮説が残る構造を保つ。
3. **探索範囲と1歩の移動量を分離する。** 広角な方位仮説・異なる累積倍率・checkpointからの再生で探索する。遠方への再局在が必要なら、それを通常歩行辺と区別する。
4. **候補生成を先に、代表軌跡選択を後に検証する。** 祖先経路でも非現実的な救済辺は消えない。逆に正常な粒子だけでもcurrentの平均接続は飛び得る。
5. **既存のESS・死亡枠補充・checkpoint・広角fallbackを再利用する。** 第一段階で閾値、rejuvenation、PDR側の方位連続化、歩検出を同時に変えない。
6. **新方式の既定化は最後。** 比較用の明示的切替を設け、現行分岐・乱数順序・出力契約を維持する。設定既定値変更は別途確認を受ける。

## ④ 推奨する修正プランと確率モデル

### 4.1 まず現モデルを明示し、追加のPDR残差尤度を置かない

状態を `x_k=(p_k,c_k,d_k,s_k,m_k)`、センサー由来入力をu、地図をMとする。cは既存の持続方位補正、dは減衰drift、sは歩幅倍率、mは離散運動状態である。

既存の通常提案をF、既存因子をGとして、当面の比較対象を次の操作的な粒子モデルに固定する。

\[
\gamma_k(x_{0:k})\propto\gamma_{k-1}(x_{0:k-1})
 F_k(x_k\mid x_{k-1},u)G_k(x_{k-1},x_k;u,M).
\]

Fには `proposal.py` の観測を使う状態抽出も含め、Gには地図の0/1、倍率prior、予測尤度の0.1乗、必要な場合だけBLE因子を含める。これは既存のヒューリスティックを含むFeynman–Kacモデルの定義であり、全因子が独立観測から導出された厳密な生成モデルだという意味ではない。

一般の提案qでは増分重みは `w_old × F × G / q`。q=Fなら新たに同じPDR歩幅のガウス密度を掛ける必要はない。同じ距離情報を再度尤度にすると、補正すべきPDR中心へ分布を狭めるおそれがある。独立距離観測があれば、その誤差モデルを別途導入できる。シグモイドにするだけでは独立性も重要度補正も得られない。[SMCの一般式の参照](https://www.stats.ox.ac.uk/~doucet/doucet_johansen_tutorialPF2011.pdf)

倍率priorと0.1乗因子自体の妥当性は残るが、救済変更と同時には修正しない。将来の独立アブレーションとする。

### 4.2 有限候補による地図考慮提案を推奨

単に「通れるまで引き直す」と、親ごとの通過確率Zが異なるのに全親を同じ重みで救済してしまう。地図条件付き提案 `q=F I_M/Z(x_old)` を使うなら、増分重みにZが必要である。現行円内救済にPDR密度を掛けるだけでは、この問題も解消しない。

そこで、最初の実装候補には次の**固定Kの候補バンク方式**を選ぶ。

1. 正重みを持つ各親について、同じ通常提案FからK個の完全な候補状態を独立生成する。衝突した親だけ後から追加抽出する方式にはしない。
2. 各候補jの `a_ij=G(x_old_i,x_ij)` を、同じ地図判定・既存因子で計算する。
3. `S_i=Σ_j a_ij` が正なら `P(J=j)=a_ij/S_i` で1個を選び、選択した状態を丸ごと採用する。
4. この親からの未正規化重みは `w_i × S_i/K` とする。S_i=0なら重み0。後段の既存ESS/補充/集団復旧へ渡す。

これは候補バンクを含む拡張空間での重み付けで、任意の試験関数hについて

\[
E\!\left[\frac{S_i}{K}h(X_{iJ})\right]
=\int F_k(x\mid x_i,u)G_k(x_i,x)h(x)\,dx
\]

が成立する。選択候補のGをさらに重みに掛けない。K=1は円内救済なしの通常予測へ帰着する。**Kを増やしても目標F・Gを狭めない**ことが、単なる歩幅一致強制に対する利点である。有限N/Kや既存rejuvenation・復旧を含む全系の不偏性まで保証するものではない。

実装ではN個の採用状態へ畳み込んでから既存ESS判定へ渡す。候補K×NのESSを現在のN基準と混ぜない。集団復旧の生存率判定には「候補バンク内に正のGがある親の割合」を用いることを明記し、候補1個あたり通過率も別に保存する。K増で生存親率が上がるので、従来値との比較に定義を併記する。

Kは4、8、16を比較する設計候補とし、既定値ではない。計算予算に応じ実装前に絞る。採用基準は精度・多様性・復旧・時間の比較であり、最大Kを自動採用しない。

### 4.3 大誤差探索は別のモデル成分として導入

上記Fが狭すぎる場合、Kを増やすだけでは補えない。次段階で

\[
F_{mix}=(1-\pi_k)F_{normal}+\pi_k F_{broad}
\]

を比較する。broadは広角方位、異なる倍率・バイアスの仮説を生成し、座標を同じ歩行方程式で作る。5m円位置を通常1歩の状態として隠して混ぜない。混合率・方位分散・倍率範囲は未決定で、独立計測・合成誤差で校正する。まず固定の少数成分とし、衝突後だけ無記録に分布を切り替えない。

`q=F_mix`としてバンクを作れば、そのモデル内では追加のf/qは不要。一方、目標Fを通常モデルに固定し提案qだけ広げるならF/qが必要であり、通常Fがほぼ支持しない大誤差を補正する能力は増えにくい。「探索を広げる」と「誤差モデルを広げる」を区別する。

通路方向・センサー観測を使う混合提案は既存研究にもあるが、ロボットの距離センサーを用いるMCLの結果をこのPDRへ直接転用しない。本案は独立測距がない条件での運動誤差モデルの比較である。[Thrun・Fox・Burgardの混合提案研究](https://www.cs.cmu.edu/~thrun/papers/old/thrun.mclmix.html)

大きな累積位置誤差には既存checkpointから複数歩を再生する。既存窓より古い誤枝が復旧できなければ、窓拡張を別の変更として比較する。地図全域への再局在が必要なら、状態resetイベント・履歴接続不明・別区間として明示し、長距離変位を通常の歩行距離へ算入しない。位置誤差からは除外せず、reset回数・変位・復旧時間も失敗も報告する。

### 4.4 実移動と内部状態の関係

通常候補では、状態別基準方位Hと歩幅Lを用いて

\[
\theta_k=H_k(m_k)+c_k+d_k+e_{\theta,k},\qquad
\ell_k=L_k(m_k)s_k\exp(e_{L,k}),\qquad
p_k=p_{k-1}+\ell_k(\cos\theta_k,\sin\theta_k)
\]

と記述できる。最初の候補方式では既存の乗算正規ノイズ・clipをそのまま使い、上式の対数長モデルへの変更は同時に行わない。eは一歩だけの残差を表す設計上の記号である。

| 量 | 意味・次歩への反映 |
|---|---|
| c (`heading_correction`) | 独立アンカー等で裏付ける持続補正。壁回避角を直接代入しない。 |
| d (`heading_drift`) | センサー方位と地図の整合で選択される一時的・相関する誤差。既存保持率で次歩へ減衰。 |
| s (`stride_scale`) | 時間相関する倍率。1歩の救済距離/PDR歩幅で毎回上書きしない。 |
| eθ、eL | 一時的偏向・歩幅残差。次歩へ直接持ち越さない。候補ID・分岐とともに記録する。 |
| broad成分の持続性 | 一時残差を広げる仮説と、drift/倍率状態を広げる仮説を分けて比較する。持続バイアス状態の追加は後者でも不足する証拠がある場合のみ。 |

採用した完全状態から実変位を再構成できることを不変条件にする。ゼロ変位では実方位を未定義として扱う。地図によって採用状態を選ぶことは補正であり、位置を変えて状態を後付けすることとは異なる。候補分布から抽出した一時残差で説明される方位差は不具合扱いしない。

親履歴は選択した前歩の親へ接続する。生存粒子複製では複製元の親・状態・重みを使い、死亡スロットの前位置から移動距離を計算しない。再生時は履歴、親、drift、倍率、運動状態、スコア、診断を同じ範囲で更新する。

過去ログではrecovery角の恒久補正化が悪化し、減衰driftへ戻して回復した記録がある。これは別データ・過去条件の証拠であり、今回の数値ではない。一時回避と長期バイアスを分ける設計上の警告として使う。

### 4.5 最終軌跡は「実在する祖先経路」の選択を第一候補にする

予測改善後もcurrentの任意代表点接続は別問題として残る。最初の新選択器には、終端に残る**完全な祖先経路候補の重み付きmedoid**を推奨する。各時刻の平均点を新たに連結しない。

\[
\hat P=P^{j^*},\quad
j^*=\arg\min_j\sum_l W_l\sum_{k=1}^{T}\alpha_k
\|p_k^j-p_k^l\|^2.
\]

Wは終端粒子重みを同一の完全経路へ集約した質量、αは事前に固定した時刻重み。一本の実在経路を選ぶので祖先関係と既存の合法辺を維持する。距離を短くするコストやPDR残差尤度は追加しない。これは有限粒子による経路分布に対する代表経路の意思決定であり、真のMAPや新たな測位観測ではない。概念上の粒子経路・smoothingの区別は[SMC文献](https://www.stats.ox.ac.uk/~doucet/doucet_johansen_tutorialPF2011.pdf)に基づくが、medoidという選択は本計画の提案である。

最初は最大500終端の全候補で評価し、重複経路を集約する。距離計算はO(TN²)、距離行列はO(N²)。計算削減の候補打切りは後回しにする。選択器から消えた正解枝を復元することはできない。複数通路ではmedoidが誤枝を選ぶこともあるため、上位の異なる経路・質量を比較出力へ残す。

現行sequenceは比較対象として維持する。経路スコアの付け直しと代表選択の変更を混ぜない。バンクの増分重み `S/K` は周辺化の補正で、選択された一経路の遷移対数密度ではない。これをそのまま既存path scoreへ加え、厳密な経路確率と称してはならない。

A2/A3で旧sequenceとguardを比較するときは、親の旧スコアに、選択候補の従来 `observation_log_likelihood`（倍率prior・運動状態予測因子・BLE因子の対数）だけを加える。地図無効は従来どおり候補外とし、S/Kや新たな運動密度を旧スコアへ足さない。この値は旧方式との比較用スコアであり、新モデルの厳密な経路確率ではない。復旧時の既存スコア更新も維持する。

新選択器ではBLE reset・anchor前後の接続規約が決まるまでBLEなしのみを対象とする。比較上はcurrent・現行sequence・実際のfinalをすべて保存する。有効祖先経路がない場合は失敗を明示し、壁合法な遠方currentへ無条件に切り替えて成功扱いしない。

### 6.4 判断基準

1. **実装安全性:** 非有限値・親不整合・状態再構成の破綻は0。BLEなしでは生存親子辺と採用経路の壁交差0。合成の既知の実行可能ケースで復旧失敗・終端誤方向は0を必須とする。基準にも失敗があれば未達として残す。
2. **症状改善:** 再配置由来の裾の大変位、最終ジャンプ、未支持逆行が計測別・最悪seedでも減るかを確認。holdへの置換、総距離の過小化、通過点の欠落で帳尻を合わせた案は採用しない。
3. **補正能力:** 誤方位・誤倍率の合成試験と正解評価で、PDRと異なる妥当な解を保持できること。PDR比が1へ近づくだけでは未達。
4. **精度:** 登録済み正解では位置・通過点誤差の中央値改善と、計測別最大誤差・seedばらつきの非悪化を確認する。許容差は計測誤差と用途から事前に定める。根拠のないm単位閾値を後付けしない。精度と復旧が競合した場合はPareto比較を示して保留する。
5. **証拠の限界:** Aに正解がなければ結論は「運動モデル・連続性の改善」まで。全般的な測位精度改善や既定採用はB/Dの独立評価を待つ。

既存ground-truth Skillの壁交差・recovery failure・終端方向failureの基準を再利用し、今回必要な距離・祖先・真の復旧率を追加する。既知の誤枝があるデータを平均で隠さない。

## ⑦ リスク・副作用

- **大誤差復旧の低下:** 大変位を削ると偶然の正解領域への復帰も失う。広角成分・状態仮説・再生で代替できるかは未確認。復旧遅延と正解枝生存を測り、不足なら採用を保留する。
- **分布の過度な集中:** 生存複製・地図受理・反復再標本化で少数枝へ集中する。K増も枝保持を保証しない。枝quotaを使う場合は既存helperを再利用し、重み補正・質量保存の意味を先に決める。
- **持続誤差と一時偏向の取り違え:** driftを強く減衰すると持続biasを学習しにくく、弱めると局所回避が残る。保持率変更は救済方式と別に評価する。
- **地図誤差への過適合:** 画像しきい値・縮尺・起点・壁幅の誤差を誤方位へ吸収する可能性。地図登録の不確かさを確認し、人体半径や壁膨張を同時変更しない。
- **候補バンクの有限標本誤差:** K不足で全候補が棄却される。K増で費用が増え、生存率・復旧の発動頻度も変わる。これはアルゴリズム差として記録する。
- **長さモデルの支持範囲:** 歩数欠落、走行、停止、階段は現在の1歩モデル外になり得る。誤検出までPFの位置ジャンプで救わず、適用範囲・入力品質を別評価する。
- **選択器の限界:** medoidでも誤通路・残存大変位を選べる。終端祖先の縮退は後処理で修復できない。選択方式の改善だけを精度改善としない。
- **BLE・履歴互換性:** 現在はresetを含むrunでsequenceが無効になる。新候補とBLE尤度、reset親情報、history候補の接続は別途試験が必要。

| 案 | 判断 |

| 壁反射・壁沿い投影 | 端点処理は簡単でも、人が反射して歩くモデルではない。写像の確率質量・角の多価性・曲がり角での誤誘導を別設計する必要がある |
| 地図軸への強制整列 | 斜行・旋回・横歩きと地図登録誤差へ弱い。密度が定義できる提案としての利用は将来候補 |
| currentの距離上限だけ追加 | 粒子救済辺を修復せず、真のPDR補正まで棄却し得る。粒子改善後の補助比較に留める |
| 位置だけのhistory DP・移動平均 | 既存history候補は別出力として存在。ジャンプを減らしても短縮・系譜変更・状態不整合を招くため新たに重複実装しない |
| 全期間の厳密なsmoother/経路MAP | 遷移・提案・再生の確率、clip境界の点質量、一歩残差と持続状態を定義し直す必要がある。初期修正には大きすぎる |

## ⑨ 実装前に確認すべき事項

**必須の確認**は次の通り。今回の計画作成を止める条件ではなく、実装・長時間評価・既定変更の前提である。

1. A群に対応する真のルート、通過時刻、独立区間距離、手動歩数は取得可能か。地図登録済みtruthがなければ精度の採否は保留する。
2. B群の既存truthが各反復計測に対応すること、座標・起終点・mapが正しいこと。古い試験値を現行基準へ転用しない。
3. リアルタイムの出力が必要か、全歩後の研究用軌跡でよいか。現finalizeと推奨medoidは全系列を使う。固定遅延化には別の評価が必要。
4. K・seed追加・合成ケース数・再生窓の計算予算と許容遅延。broad成分の範囲は未決定で、実装前に試験条件を確定する。
5. 「大誤差復旧」に期待する範囲は方位・倍率誤差か、歩数欠落か、既に失われた通路からの再局在までか。後者は通常1歩モデルとは別のreset/履歴規約が必要。
6. 比較用設定/APIの公開範囲、既定値維持、復旧失敗時の扱い、複数候補の保存形式。旧方式を選べることを必須にする。
7. 混合成分の一時残差と持続biasの切り分け、候補Gと重み補正とpath scoreの定義。コード作成前に離散合成モデルで数式を固定する。
8. BLEのどの方式まで今回の改善後に保証するか。初期評価はBLEなし、既存BLE分岐の非回帰を確認した後に拡張する。

最初の実装判断はフェーズ0～2に限定するのが妥当である。混合探索・復旧拡張・新選択器は、それぞれ前段の比較結果を見て進める。精度や復旧を失う変更は、ジャンプが減っていても採用しない。
