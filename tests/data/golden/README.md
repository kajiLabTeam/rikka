# 数値回帰の参照値

- `refactor_golden.json`: 5807a74で保存した旧地図条件のPDR/PF出力。履歴として保持し、PDRの回帰は引き続きこの値を使う。
- `refactor_open_map_golden.json`: **同じ旧実装5807a74**を、全画素通行可能な3000×2000地図・起点(2050,400)・scale=.01で実行したPF出力。現在の実装から期待値を生成していない。

2026-10-24、実地図の変更とPF既定ノイズの更新が旧goldenテストへ混入していたため、
テストの地図とPF設定を固定した。設定は`tests/conftest.py`の`legacy_particle_profile`。
元のセンサー入力、seed=42、100粒子、固定peak検知は維持する。

切り分けでは旧実装も同じ合成地図で実行し、現在の固定プロファイル実行との軌跡差が
最大1.78e-15mである一方、旧地図の参照値とは最大約0.164m異なることを確認した。
このため既存の値を一括更新せず、旧地図の値を保存したまま、独立した自由空間の参照を追加した。
壁・地図制約の回帰は`test_pdr_regressions.py`等の専用地図テストで検証する。

参照の再生成は、旧コミットの`src/`を一時ディレクトリへ`git archive`で展開し、
その`src/`を`PYTHONPATH`へ指定して旧`rikka.analyze.pdr.run`を実行する。
各入力CSVを読み、合成地図と上記条件でPFを実行し、`trajectory.csv`、`step_lengths.csv`、
`step_headings.csv`（方位はラジアンへ変換）を保存する。製品ソースや旧参照値は上書きしない。
この参照は数値回帰用であり、測位精度の正解データではない。
